# Q4 W6 result directories

`feasible_region/` is the 30-case pilot for the new persistent-bearing
certificate. `feasible_region_full/` is the 200-case validation using the same
seed matrix as frozen W5 (random 0:100, min_reff 10000:10050, collinear
10000:10050).

The older files directly under this directory are historical W6-A assets and
were intentionally not overwritten. They are not evidence for the new W6.
